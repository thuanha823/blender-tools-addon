## Workflow
##### _* More settings available_

#### **Quick Collection**
- Create a new collection and name after active object
#### **Quick Mirror** *
- Quickly mirror selected objects across a specific axis
#### **Auto Bevel Weight** *
- Apply Bevel Edge Weight based on angle threshold
#### **Export at Origin** *
- Export selected objects in various format, centered at world origin

## Clean Up Resources
#### **Wipe Scene**
- Reset scene to default
#### **Clear Viewport**
- Delete all visible objects
#### **Wipe All Materials**
- Delete all materials in scene, regardless of Fake User
#### **Purge Data**
- Delete all unused data such as nodes, image, or materials

## Group Similar Materials
#### **Rename - All**
- Strip .00x suffix from all materials in scene
#### **Rename - Selected Objects**
- Strip .00x suffix from selected object materials

## Custom Orientation
#### **New**
- Quickly create a new transform orientation based on selected vert/edges/faces
#### **Delete Custom**
- Delete all previously created orientation

## Index Assign
#### **Material** *
- Assign a unique Pass Index to all materials
#### **Objects** *
- Assign a unique Pass Index to objects
#### **Reset Pass Index** *
- Reset all Pass Index to 0
